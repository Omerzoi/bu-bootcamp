# BU CS Foundations Bootcamp

Boston University Online AI Programs CS Foundations Bootcamp.

- module2/ : Java programming fundamentals, including variables, control flow, methods, and file handling
- module3/ : Data structures and basic object-oriented programming concepts
- module4/ : Version control using Git and GitHub
 
## Programs

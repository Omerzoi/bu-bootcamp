# What I Learned

These four modules gave me hands-on practice with Java programming, data structures, object-oriented programming, and version control.

- Module 1: Created a basic HelloWorld greeting program that takes my name as keyboard input and greets me. I learned how to use Scanner from java.util for user input and System.out.print for console output.
- Module 2: Created a basic GradeAnalyzer program that reads and validates scores from a file, processes the data, and generates a report with the calculated average and grade distribution. This helped me practice file handling, validation, loops, methods, and exception handling.
- Module 3: Created a basic ContactManager program using different data structures such as ArrayList and HashMap. I also practiced basic object-oriented programming concepts by organizing the application around classes and objects.
- Module 4: Practiced using Git and GitHub for version control, including tracking changes, staging files, creating commits, and managing my project repository.

These modules gave me practical experience with Java and version control.
